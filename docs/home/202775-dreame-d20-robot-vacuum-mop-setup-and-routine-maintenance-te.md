== ***Step 1 — Position the Charging Dock*** ==
# Place the dock against a wall on a flat surface.
# Leave at least 0.5 m clearance on both sides and 1.5 m in front.
# Plug the dock into a power outlet.
# Keep the area clear for reliable docking.
== ***Step 2 — Charge the Robot*** ==
# Place the Dreame D20 on the dock.
# Ensure the charging contacts align correctly.
# Allow a full charge before first use.
# Charging indicators will confirm status.
== ***Step 3 — Install the Mop Module*** ==
# Fill the water tank with clean water.
# Attach the mop pad securely to the holder.
# Slide the module into the rear of the robot until it clicks.
# Remove the module when vacuum-only cleaning is desired.
== ***Step 4 — Prepare for Cleaning*** ==
# Remove cords, toys, and loose items from the floor.
# Open doors for rooms you want cleaned.
# Close off areas not intended for cleaning.
# Raise curtains to prevent tangling.
== ***Step 5 — Start a Cleaning Cycle*** ==
# Press the power/clean button on the robot or use the mobile app.
# Select vacuum, mop, or combined mode.
# The robot will map and clean systematically.
# It will return to the dock automatically when finished or low on battery.
== ***Step 6 — Empty the Dust Bin*** ==
# Power off the robot.
# Remove the dust bin from the top cover.
# Empty contents into a trash bin.
# Reinsert until it locks in place.
== ***Step 7 — Clean Brushes and Filters*** ==
# Remove the main brush and side brush.
# Cut away hair and debris carefully.
# Rinse the filter with water only.
# Allow all parts to dry completely before reinstalling.
== ***Step 8 — Common Issues*** ==
* ***Poor suction:*** Full dust bin or dirty filter
* ***Mopping streaks:*** Dry or worn mop pad
* ***Navigation errors:*** Obstructed sensors or cluttered space
* ***Docking failure:*** Dock misaligned or blocked
