== ***Step 1 — Initial Inspection*** ==
# Unbox the laptop carefully.
# Check for shipping damage or loose ports.
# Ensure vents and keyboard are unobstructed.
# Verify the serial label is intact.
== ***Step 2 — First Power-On Setup*** ==
# Connect the USB-C charger.
# Power on and follow on-screen setup prompts.
# Complete OS updates before regular use.
# Restart once updates finish.
== ***Step 3 — Thermal & Vent Care*** ==
# Place the laptop on a hard, flat surface.
# Avoid blocking bottom or rear vents.
# Use compressed air monthly to remove dust.
# Prevent prolonged use on soft bedding.
== ***Step 4 — Battery Health Technique*** ==
# Avoid frequent full discharges.
# Enable battery conservation mode if available.
# Unplug once fully charged when possible.
# Store between 40–60% charge if unused.
== ***Step 5 — Keyboard & Display Protection*** ==
# Clean keys gently with a dry cloth.
# Never spray liquid directly on the keyboard.
# Close the lid slowly to protect hinges.
# Avoid pressure on the display panel.
== ***Step 6 — Transport & Daily Handling*** ==
# Use a padded sleeve or case.
# Disconnect peripherals before moving.
# Carry from the base, not the screen.
# Keep liquids away during use.
== ***Common Issues Prevented*** ==
* Overheating due to blocked airflow
* Premature battery wear
* Keyboard damage from moisture
* Screen pressure marks
