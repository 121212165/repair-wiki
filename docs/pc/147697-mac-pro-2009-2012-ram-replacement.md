Upgrade or replace your Mac Pro's RAM.

## 需要的配件

- 8GB OWC Memory Upgrade Kit
- 16GB OWC Memory Upgrade Kit
- 32GB OWC Memory Upgrade Kit (8 core only)

## 步骤

### 第 1 步：Remove the side panel

Pull the side panel release latch upwards until you hear an audible click.
Lift the side panel off towards you from the top.

![步骤图](https://guide-images.cdn.ifixit.com/igi/FeMVEeIJNOe4n4Mc.medium)

![步骤图](https://guide-images.cdn.ifixit.com/igi/k54ceqhvqDsHLKXe.medium)

### 第 2 步：Remove the Processor Board

Press the two latches (circled in red) holding in the processor board. They might need a bit of pressure to open.
Slide out the processor board.

![步骤图](https://guide-images.cdn.ifixit.com/igi/nGPcjIsLELXjskLv.medium)

![步骤图](https://guide-images.cdn.ifixit.com/igi/udukHDI4BTFxSy1Y.medium)

### 第 3 步：Remove the old RAM

Push the RAM tabs down to release the sticks.
When reinstalling the RAM, you might need to apply some force to fit the sticks back in.
Repeat this step for each stick of RAM you want to replace.
