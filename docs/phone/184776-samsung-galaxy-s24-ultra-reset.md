What is the reset code for a Samsung device?

For Samsung devices, the Android factory reset code is ''#''#7780#*#*. If the other code does not work, there is a custom restart code which is ''2767''2878#

How to reset a phone with buttons?

Release the Power ***button*** and hold the Volume + ***button***: the ***Android*** Recovery menu appears. Using the Volume down ***button***, select Wipe data/factory reset. Confirm ***with*** the Power ***button***. The next screen displays, Wipe all user data?
